Forex Local Visual v0.2.0 improves safe local use, offline contribution and verifiable source releases.

### Added
- Deterministic synthetic demo for all 12 instruments, with existing-data refusal and atomic dual-table inserts.
- Isolated verification command: configuration and migration checks plus network-blocked tests.
- Linux/macOS/Windows Python 3.12 CI and Linux Python 3.13 CI.
- Tested dependency constraints, pinned GitHub Actions, dependency update proposals, contribution templates and a prioritized engineering roadmap.
- Source archives, SHA-256 checksums and tag/version/commit validation before publication.
- Preserved ECharts 5.6.0 upstream license/notice files; the existing bundle was verified byte-for-byte against the official release.

### Fixed
- Chart query validation, invalid/empty-symbol handling, open date ranges and inclusive UTC end dates.
- Chart endpoints now return ECharts JSON objects instead of double-encoded JSON strings; included pages support both.
- Production mode rejects weak/default secrets and unspecified/wildcard hosts, and enables secure cookies and HTTPS redirects.
- Explicit UTC scheduler registration, per-process instance limits and coalescing. Import still does not start a worker.
- Includes the historical and recent import protections merged since v0.1.0: isolated batches, validation before replacement, rollback on database errors, duplicate handling and historical regression rejection.

### Compatibility
No model migrations are introduced by this release. Use a separate empty database for seed_demo. External chart clients should remove a redundant second JSON parse. Requirements target Django 5.2 LTS.

This remains a local research application. Real provider access, public deployment, multi-process scheduler locking, recent-data coverage thresholds and data provenance are not certified by this release. Provider market data is not bundled; demo prices are synthetic.
